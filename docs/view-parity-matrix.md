# View parity matrix

Generated by `scripts/view_parity_matrix.rb` from `src/ui/views` and
`src/ui/renderers`; do not edit by hand. A cell reads `read/declared`:
how many of the view's declared attributes (its own and inherited) the
renderer's visit consults, directly or through its shared attribute
helpers. `—` means the renderer has no visit for the view. A read is
evidence the renderer consults the attribute, not proof it honors every
value; the platform tier documents and device suites carry that proof.

iOS only: ActionSheet, ActivityRings, ContextMenu; Android only: none;
neither phone: ActivityRing, Complication, ComplicationWithWebFallback, Gauge, Panel, PathControl.
