# Support matrix

Generated by `ruby scripts/support_matrix.rb` from the pins, the workflows and
`config/support_proof.yml`. Do not edit by hand: change a source, rerun the
script, commit the result. CI runs it with `--check` and fails when this file
is stale. What "supported" means, and how a new OS release enters this table,
is in `docs/compatibility-policy.md`.

## Android

Supported runtimes: **Android 12 (API 31) through Android 16**.
The floor is `ANDROID_MIN_SDK`; the ceiling is the newest lane of the pull-request
gate. API levels between the lanes are supported by policy and not exercised by
CI; the newest released runtime is exercised nightly, not supported, until its
lane is stable enough to join the gate.

### Pins (`config/android_toolchain.env`)

| Pin | Value | Meaning |

| `ANDROID_TARGET_SDK` | 36 | behavior level the app opts into (Android 16) |
| `ANDROID_COMPILE_SDK` | 36 | platform the Kotlin and Java sources compile against |

| `ANDROID_BUILD_TOOLS_VERSION` | 36.0.0 | build tools |
| `ANDROID_NDK_VERSION` | 28.2.13676358 | NDK |
| `ANDROID_AGP_VERSION` | 8.13.2 | Android Gradle plugin |
| `ANDROID_GRADLE_VERSION` | 9.3.1 | Gradle (wrapper and distribution SHA-256 pinned beside it) |
| `ANDROID_KOTLIN_VERSION` | 2.2.21 | Kotlin |
| `ANDROID_JAVA_VERSION` | 17 | JDK major |
| `ANDROID_SUPPORTED_ABIS` | arm64-v8a,x86_64 | packaged ABIs (default `arm64-v8a`) |
| `CRYSTAL_ANDROID_VERSION` | 1.21.0 | Crystal compiler every lane installs |

### CI lanes (`.github/workflows/android-native.yml`)

Runner `ubuntu-24.04`, image `google_apis` `x86_64` `pixel_6` (4 cores, 4096 MB), one job per runtime, `make test-android` on each through `scripts/ci/android_emulator.sh`. Triggers: pull request, push to main, schedule (17 6 * * * UTC), manual dispatch.

| Runtime API | Android release | Role |
| --- | --- | --- |
| 31 | Android 12 | the floor (`ANDROID_MIN_SDK`) |
| 35 | Android 15 | an intermediate release |
| 36 | Android 16 | the target (`ANDROID_TARGET_SDK`) |
| 37.0 | Android 17 (SDK 37.0) | the newest released runtime (`ANDROID_NEXT_RUNTIME`): `android-next.yml`, push to main, android-target, schedule (47 5 * * * UTC), manual dispatch; its own issue lane, never the pull-request gate |
